# Security and privacy

The standalone app needs its own Screen Recording permission. Accessibility is optional for detecting individual content elements. Carbon hotkeys require no Input Monitoring permission. Hammerspoon is not required. Keep macOS permission decisions under the user's control; never modify TCC databases. Builds are currently ad-hoc signed, not Apple notarized.

Screenshots, thumbnails, OCR text and history metadata are local files. Redacted exports do not remove the original history image. Do not attach private screenshots, tokens or full clipboard contents to an issue.

Please do not publish exploit details or private data in a public issue. Use GitHub's private vulnerability reporting option if the repository offers it. Otherwise open an issue asking for a private reporting channel without including the sensitive details.

Version 5 introduces the independent app. The previous Hammerspoon-based release is retained under tag v4.2.0. Fixes target the latest source. There is no independent security audit or support SLA.
