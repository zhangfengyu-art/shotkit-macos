# Changelog

## 4.2.0 — First public release

- Native AppKit capture toolbar with Liquid Glass on supported systems.
- Hover, press, release, drag cancellation and contextual long-press feedback.
- Resident background OCR, separate barcode scanning and startup recognition preparation.
- System Translation with fast/high-fidelity modes, cancellation, retry, stale-result protection and bounded memory caches.
- Selection stabilization, annotation, pinning, searchable local history and manual segmented long screenshots.
- Portable installer with backups, dry runs and restoration; no user data bundled.
- Chinese and English installation documentation, source tests and reproducible release packaging.

This is the first public distribution of a tool developed and tested locally. The 4.2 version identifies its current codebase; it does not imply earlier public releases.
