# ShotKit macOS

独立运行的原生 macOS 截图应用。按 **⌃⌘A** 选区截图，按 **⇧⌃⌘A** 打开历史。

**5.0 起不再需要 Hammerspoon、Lua 或 Python 来运行。** 快捷键、选区交互、截图、标注、翻译和历史都由同一个原生应用管理。

[English](docs/README.en.md) · [旧版 Hammerspoon 版本](https://github.com/zhangfengyu-art/shotkit-macos/tree/v4.2.0)

## 安装

需要 **Apple Silicon Mac、macOS 15 或更新版本**。

1. 解压发行包，将其中的 **ShotKit.app** 拖到“应用程序”或 `~/Applications`，双击打开。
2. 首次打开会显示设置与权限窗口。点“屏幕录制”的“去设置”，在系统设置中允许 **ShotKit**。如系统要求退出并重新打开，请照提示操作。
3. 回到 ShotKit，点“重新检查权限”，再点“开始截图”。菜单栏中的取景框图标始终可打开截图、历史和设置。
4. **辅助功能是可选的**：允许后能自动选择图片、按钮和内容块；不开启也能按窗口选择和自由框选。快捷键注册不需要“输入监控”权限。
5. 需要随登录启动时，在设置中打开“登录时启动 ShotKit”。默认不会替你开启。

当前构建为临时签名，**尚未经过 Apple 公证**。macOS 可能要求你在“隐私与安全性”中明确允许打开；也可以从源码自行编译。请保留系统安全保护。

临时签名的应用重新编译后，系统可能要求重新授权。如果设置中的开关已开、应用仍显示未允许，请先退出 ShotKit，在对应权限列表移除旧 ShotKit，再添加实际安装位置的新版应用并允许，最后重新打开。辅助功能和屏幕录制分别管理；无需给 Hammerspoon 增加权限。

### 从 4.2 / Hammerspoon 升级

先安装新应用、允许它录制屏幕。独立应用获得自己的系统权限，旧版 Hammerspoon 的权限不会自动转移。

自动迁移工具可复制应用、备份配置，并且**只停用旧截图模块**：

```sh
python3 scripts/install.py --dry-run --migrate-hammerspoon
python3 scripts/install.py --migrate-hammerspoon
```

它默认安装到 `~/Applications/ShotKit.app`，把 `~/.hammerspoon/init.lua` 中独立一行的 `require("screenshot").start()` 替换为说明注释，并通过 Hammerspoon 自身 IPC 停止该模块。其他 Lua 脚本不会被重载、退出或改写。如果启动写法不同，工具会停止并提示手动处理。

若 IPC 不可用，退出正在进行的截图后，手动 Reload Config，释放旧快捷键；再在 ShotKit 中点“重新检查权限”。不要同时启用两套截图快捷键。

旧历史留在原目录；新应用可以直接显示它，不会自动搬走或清理旧文件。独立应用退出后，你仍可以单独使用 Hammerspoon 的其他自动化。

## 截图与操作

- 移动鼠标自动选窗口或内容，拖动自由框选；滚轮 / Tab / 上下键切换范围。
- 设置中分别调整“滚轮切换灵敏度”和“自动识别响应”。滚轮默认偏稳，累计滚动才切换一级，触控板忽略惯性；自动识别默认快速响应。下次截图生效，手动框选及 Tab / 上下键不受滚轮设置影响。
- 单击确定后出现工具栏。拖动选区内部移动，拖动八个控制点调整大小。
- Return / C 复制，E 标注，O 提取文字，T 翻译，P 贴图，S 保存，L 长截图，Q 读码，D 延时，A 复制并打开 AI 应用。
- Esc 在截图、工具栏、延时等待和长截图期间全局取消；右键重新选择。方向键微调位置，Shift 微调大小，Option 以 10 点步长调整。
- 双击选区可快速复制。设置中可开启“松开鼠标直接复制”。
- 工具按钮支持悬停、按下、松开、拖出取消、长按和右键菜单；高亮与实际命中范围贴合圆角边界，跟随系统深浅色及“减弱动态效果”。

标注包含箭头、矩形、画笔、文字、不透明遮盖、马赛克、裁剪、撤销和重做。文字识别结果可编辑、复制或另存为 TXT。读码只显示内容，不会自动打开链接。

翻译使用 Apple 系统 Translation，自动识别语言，可选择目标语言、快速／精细模式、停止与重试。首次使用某组语言可能需要系统下载资源。原生 Liquid Glass 需要 macOS 26+，增强玻璃交互需要 macOS 27；较早系统采用系统材质。快速／精细策略需要 macOS 26.4+。

### 长截图

只框选滚动内容区，点“长截图”。手动向下滚动，保留至少三分之一重叠，再点“取下一段”（⌃⌘A）。至少两段后点“完成并拼接”（⇧⌃⌘A），检查接缝，再复制或保存。最多 20 段。取消或失败的分段留在本机历史目录的 `long-…` 文件夹，方便恢复。

这不是自动滚动整页；固定浮层、重复背景或重叠不足可能使拼接失败。

## 原生架构与性能

- Carbon 全局快捷键；AppKit 选区窗口直接处理鼠标与键盘，没有 Hammerspoon 事件桥接。
- ScreenCaptureKit 获取屏幕快照，并排除本应用窗口。选区结果从内存裁出；不启动 `screencapture` 子进程，不等待工具栏消失再截取。
- 截图开始时复制为独立像素，选区期间以不透明冻结画面覆盖原屏幕；工具栏按选区居中，底部空间不足时移到上方。结束或取消后释放快照。选区的轻量动效使用 Core Animation；空闲时没有 60 Hz 选区轮询。
- AX 查询异步、有超时、合并和旧结果检查，避免阻塞输入。坐标在进程内保持原生类型，按钮等小控件可单独选择，装饰性边框不参与自动选区。
- PNG 保存和历史缩略图在后台队列执行。翻译窗口直接接收内存图片，随后并行保存历史。
- 单进程内复用标注、文字、翻译和历史窗口；取消 OCR / 翻译会使旧回调失效。

“内存裁图耗时”不等于从按键到最终结果的总耗时。实际延迟仍受系统截图、OCR、语言资源和翻译计算影响；请用同一台机器、同一区域比较冷启动和连续使用。

## 本机数据与隐私

新截图保存在 `~/Library/Application Support/ShotKit/Screenshots/`。截图、识别文字及元数据不上传到项目服务器；本项目没有第三方翻译 API、账户或分析统计。

默认保留 60 张，可选 12 / 60 / 100 张；新目录超过数量、30 天或 300 MB 时，会将过期截图及旁文件移入废纸篓。旧 Hammerspoon 历史只读，不参与清理。翻译缓存仅驻留内存，有数量和大小上限。

“复制并打开 ChatGPT”只复制图片并打开本机应用，不会自动粘贴或发送。遮盖和马赛克写入导出图片，但历史中的原图仍然存在，分享前请检查导出的文件。

`status.json` 仅记录本机版本、权限状态、计数和耗时，不含图片或识别文字。

## 编译、验证与恢复

源码编译需要包含 **macOS 27 SDK** 的 Apple 开发工具：

```sh
zsh build.sh
sh scripts/test.sh
python3 scripts/package.py
```

`build/ShotKit.app` 可直接运行。测试使用合成图片，验证边框稳定、负坐标多屏、混合 Retina 比例、像素方向、取消释放、OCR、二维码、拼接、遮盖和裁剪；不截取私人屏幕。

恢复迁移前的应用与截图启动配置（先退出独立 ShotKit）：

```sh
python3 scripts/install.py --restore --dry-run
python3 scripts/install.py --restore
```

备份保留在应用目标目录下的 `.shotkit-native-backups/`。配置迁移后若被修改，恢复工具会拒绝覆盖，提示从备份手动恢复截图启动行。截图历史不会被卸载或恢复操作删除。
